## 三条线路的差价买到了什么

按这个定位推，选择规则其实很清楚：

- **访客主要在美国或欧洲**，国际线路的 1Gbps 端口和 10.9 美元档位没有明显短板，回国慢一点不影响业务。

## 配置可以自己拉，不用迁就固定套餐

圣何塞这批机器基于 KVM 虚拟化，默认 1Gbps 端口，起价那档只是最小配置，下单时能改的范围不小：

- CPU：1 到 32 核
- 内存：1 到 32GB
- 系统盘：50GB 到 1TB SSD
- 扩展硬盘：最高 1TB
- 月流量：1 到 10TB
- IPv4：1 到 20 个，页面标注为原生 IP

系统方面支持常见的 Linux 发行版，Windows 可选 10 和 Server 2008、2012、2016、2019，跑 Windows 记得把内存拉到 2GB 以上。

这种按需拉配置的模式适合需求长得不规整的人，比如只要 2 核但内存要 8GB，或者硬盘要 500GB 而流量只跑 1T。代价是配置越往上加，总价越接近同价位的独立服务器，加到某个点就该换赛道了。

## 标准线路实测：178ms 背后的路由细节

第三方测评测的是标准线路，测试机为 Intel Platinum 9242（2 核 2.6GHz）、2GB 内存、1Gbps 端口，IP 归属加州，已开 BBR。

- 国内平均 ping 约 178ms，测评提到比优化线路略高一点
- UnixBench 双核单线程 1589 分
- 硬盘 I/O 读写约 226MB/s，测评的判断是官方对 I/O 做了限制
- 流媒体解锁表现不错，跨域流媒体支持较好，原文没有给出具体平台清单

真正值得逐条看的是路由。

**电信**：去程 163 骨干网直连圣何塞，回程从电信圣何塞 POP 经 cogent 和 telia 对接 163 回来，双程直连。

**移动**：去程 CMI 直连圣何塞，回程在圣何塞对接 CMI 直连回来，也是双程直连。

**联通**：去程 AS4837 直连洛杉矶，转 telia 到圣何塞；回程走 telia 绕到欧洲，在德国法兰克福才对接联通 AS4837 回国。测评补了一句，南方地区会直接在洛杉矶回来。

联通这条回程是这篇文章里最该被记住的一条限制。从加州绕到欧洲再回中国，多出来的路程会体现在延迟和晚高峰的抖动上，而前排的导购文通常只写“三网直连”。如果你的用户里联通占比高，下单前务必用下面的 IP 自己跑一遍回程路由。

硬盘 I/O 被限速这件事也一样，跑分好看不代表能扛住高并发读写，数据库压力大的应用要提前评估。

**轻云互联**做的是圣何塞 CN2 GIA 固定套餐，1 核 1G 默认 25M 带宽，折后 28 元/月，带单 IP 5G 独享防御和 50G 集群防御，三网回程都走 59.43 回国。129 个节点测下来平均延迟 162.6ms。带宽只有 25M，线路和防御是它的卖点。小站需要高防、流量不大，这类产品更对路。

- 个人博客、外贸展示站、国内访客不多 → 国际线路，10.9 美元/月这一档
